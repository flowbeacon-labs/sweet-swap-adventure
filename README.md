# Sweet Swap Adventure

An original HTML5 match-3 puzzle game with 12 levels across three worlds, responsive touchscreen/mouse controls, score targets, special sweets, cascades, hints, sound toggle, and local progress saves.

## Play

Open `index.html` in a modern browser. Swipe a sweet toward a neighboring cell, or tap two neighboring sweets. Make matches of three or more. Meet the score target within the move limit to advance. Four-or-more matches create special sweets.

## GitHub Pages

1. Create a new **public** GitHub repository (e.g., `sweet-swap-adventure`).
2. Upload `index.html` (and this README) to the repository root.
3. Under **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`; save.
4. Open `https://YOUR-USERNAME.github.io/sweet-swap-adventure/` after deployment.
